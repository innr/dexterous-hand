# 灵巧手学习项目 · 总准备文档

> 定位：个人开发者 / 学习用途 / 遥操作 + 数据采集
> 技术路线：LEAP Hand 开源复刻（飞特舵机版）+ ROS2 + LeRobot 数据管线
> 整理日期：2026-08-25

---

## 一、项目路线

```
仿真跑通(MuJoCo) → 单指实物验证 → 三指整机 → 遥操作+数据集闭环 → (可选)补齐全手
```

- 核心竞争力在**软件**：重定向算法、ROS2、数据管线；硬件用开源方案拿来即用
- 预算：单指 ≈ ¥400，三指 ≈ ¥1,350，完整闭环 ≈ ¥2,500–4,000

## 二、系统架构

### 分层总览

```
┌──────────────────────────────────────────────────────────┐
│ 应用层   遥操作端 │ 数据采集/VLA训练 │ 抓取演示           │
├──────────────────────────────────────────────────────────┤
│ 算法层   人手重定向 │ 触觉融合 │ 抓取规划 │ 安全监控       │
├──────────────────────────────────────────────────────────┤
│ 中间件   ROS2 Humble/Jazzy + ros2_control + rosbag2      │
├──────────────────────────────────────────────────────────┤
│ 实时层   串口总线(舵机菊花链) · 控制循环 30Hz~1kHz         │
├──────────────────────────────────────────────────────────┤
│ 嵌入式   STS3215 内置驱动+磁编码器（无需自研电路）          │
├──────────────────────────────────────────────────────────┤
│ 硬件     LEAP Hand 开源结构件(3D打印) + 飞特总线舵机       │
└──────────────────────────────────────────────────────────┘
```

### 上位机软件结构

```
hand_bringup/
├── hardware/        # 舵机串口通信、关节状态/指令接口
├── controllers/     # 关节控制器（后期加导纳控制）
├── retargeting/     # Mediapipe 手部关键点 → 关节空间重定向(DexPilot法)
├── recorder/        # 多传感器同步录制 → LeRobot/HDF5 数据集
└── safety/          # 关节限位、速度限制、心跳超时急停
```

### 数据链路

```
摄像头/Mediapipe → 重定向映射 → 低通滤波限速 → ros2_control → 舵机下发
录制侧: RGB相机 + /joint_states ──统一时间戳──→ rosbag2 → LeRobot格式
```

## 八、避坑备忘

1. **时间戳同步**是数据集生命线：录制端统一时钟，录完立刻回放检查
2. **舵机务必确认 TTL 串口版**（STS3215 有 PWM 同名型号）
3. 打印件打 **2 套**：公差问题和装配失误很常见
4. 舵机不要长期堵转：19kg·cm 是峰值扭矩，手指别卡死在硬物上
5. 别提前囤货：先单指验证再批量下单，避免方案返工浪费
