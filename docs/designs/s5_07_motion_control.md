# S5-07：PD + 轨迹规划 + 速度/加速度限制接入 100Hz

## 设计决策
**STS3215 的 `IServoTransport::startSend` 只接受位置（度），不是电流或转矩。**
因此 S5-07 的 PD 是**位置指令外环**，输出为角度偏置，不能声称是电机力矩闭环。

每个关节执行：
1. 上层显式 `setTargets`，目标按软件角度限位裁剪。
2. `JointTrajectoryPlanner` 从首次有效的实测角度初始化，生成
   速度/加速度受限的 `q_ref` 与 `v_ref`。
3. `PDController` 计算 `delta_q = Kp*(q_ref-q_est) + Kd*(v_ref-v_meas)`；
   输出 `q_des = clamp(q_est + delta_q, min, max)`。
4. **独立输出整形器** `AccelerationLimiter` 约束发送位置命令的速度变化，
   用梯形积分生成 `q_cmd`，并按软限位裁剪。
5. `CommandMailbox` 只保留最新 16 路命令；通信线程保留 generation
   门禁、超时和 TC 完成检查；S5-06 反馈超时停机优先。

## 时间和状态
- 默认 100Hz，使用真实两次控制 tick 时间差 `dt`，不是假设永远 10ms。
- 首次使用 `nominal_period`；超过 `max_step=50ms`、时间倒退、反馈
  非有限或超出软限位时拒绝新命令，并请求 `StopCoordinator` 锁存。
- 首次轨迹从反馈位置开始；未调用 `setTargets` 不会自动向零位运动。
- 所有 16 路规划器、PD 和加速度限制器由 `MotionControlCore` 独占，
  只在控制线程使用；`setTargets` 用互斥锁复制目标快照。
- 轨迹和限速状态采用固定大小 `std::array<std::optional<...>>`，不在
  控制周期中进行堆分配。
- `RealtimeExecutor` 默认启用新外环；单独创建的 `ControlLoop` 仍
  保留 S4 位置直通模式，避免改变旧 S4 接口的语义。

## 初始参数（非真实舵机标定值）
- 软件角度边界 [-90°,90°]。
- 最大指令速度 60°/s、最大指令加速度 180°/s²。
- `Kp=1.0`（无量纲）、`Kd=0.05s`，仅为模拟测试起点。
- 触及软件限位时以限位优先并重置速度整形器，允许该保护动作突破
  理想加速度连续性；不保证机械制动距离。
- 以上不是 STS3215 的内部增益，也不对应其内部电流/力矩限制。

## 测试
- 16 路虚拟时间序列：阶跃目标、反向目标、输出速度与加速度上限。
- 首次命令从反馈位置平滑起步；未授权目标不发布。
- PD 速度阻尼项影响输出；超时 dt、越界反馈和非法配置拒绝。
- GitHub Actions CTest 全量回归；不涉及真实舵机动作。

## 后续风险
- 真实 16 路串口命令发送时间、反馈延迟、速度估计噪声、接触刚体振荡、
  关节零位/方向和机械限位尚未 HIL 验证。
- 外环输出受限不等于机械力/电流受限；真实硬件需要限流、过温、
  断扭矩和急停链路。
- 当前位置的外环与 STS3215 内部位置环级联，实际增益需谨慎整定。
