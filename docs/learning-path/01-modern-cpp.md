# S1 — 现代 C++17 基础

**入口**：熟悉嵌入式 C 与指针、结构体、模块化；不要求熟悉现代 C++。
**目标**：能独立编写可维护的 16 关节数据模型，解释对象所有权与析构，无需借助复杂并发来掩盖基础缺口。
**当前**：LEARNING；已讲解概念，未完成正式独立编码验收。

## 必会知识
1. C `struct` vs C++ `class`、public/private、构造初始化列表、const 成员函数、命名空间与 ODR。
2. 值/指针/引用、`const T&`、左值/右值、`std::move` 不等于立即搬移、移动构造与拷贝语义。
3. RAII；`unique_ptr` 默认唯一所有权，`shared_ptr` 引用计数及循环引用风险，避免裸指针拥有资源。
4. `std::array`/`vector`/`optional`、`enum class`、lambda、算法与范围检查。
5. 虚函数、纯虚接口、`override`、虚析构；异常和错误返回的基本边界。

## 项目任务
实现 `JointState`、`JointLimit`、`Joint`、`RobotHand<16>` 和 `IJointBackend`（不接串口）。实现 `setTarget`、`getState`、范围/非有限值检查、零位初始化和目标限幅。用 `std::array` 管理 16 关节，接口返回引用时声明生命周期前提。加入一个自定义 RAII 测试资源，证明异常和正常退出均析构一次。

## 验收测试（必须全部通过）
- S1-T01：默认构造后 16 关节均处于定义的安全初值，无未初始化数据。
- S1-T02：边界内、边界上、越界和 NaN/Inf 输入；按接口规定拒绝或限幅，不出现静默错误。
- S1-T03：`unique_ptr` 移动后源指针不再持有对象；被管对象只析构一次。
- S1-T04：复制与移动一个含 `vector` 的模型对象；数据和值语义符合设计。
- S1-T05：通过 `IJointBackend*` 删除派生对象时正确调用虚析构（仅测试虚接口场景）。
- S1-T06：故意构造生命周期错误示例，说明悬空引用、双重释放、数据所有权区别，不要求运行 UB。
- S1-T07：本人限时独立完成“添加关节限速检查并编写边界测试”（建议 60–90 分钟），无需复制 AI 完整答案。
