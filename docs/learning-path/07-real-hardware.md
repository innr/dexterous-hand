# S7 — STS3215 真实硬件联调与系统验收

**入口**：S6 PASSED，硬件风险评估及安全措施已审查。**目标**：在受控条件下验证真实 LEAP 的通信、控制时序、恢复与软硬件一致性。**不把普通软件测试称为安全认证。**

## 分阶段上电
先单舵机台架、后单指、最后整手；每一步独立验收。设备与负载固定，设置物理隔离、可达的断能方式、限流与机械保护；评估断电失去保持力带来的风险。

## 交付
STS3215 总线驱动和设备扫描、ID↔关节映射表、位置/速度/负载反馈、CRC/超时统计、总线方向切换记录、home 校准、限位、速度限制、异常恢复日志，以及真实硬件测试报告。

## 验收测试
- S7-T01：按硬件编号核验 ID 唯一、读写寄存器约定、正反向与关节限位，生成签名映射表。
- S7-T02：单关节重复 100 次受限低速往返，异常计数和最大偏差符合预先冻结的指标。
- S7-T03：测量 16 关节轮询每帧/每关节时间戳、P50/P99/max、有效吞吐；证明控制线程不会阻塞在串口 I/O。
- S7-T04：CRC 错误、响应丢失、舵机离线、串口拔插、恢复等可控故障注入，验证进入 DEGRADED/SAFE_STOP/FAULT 与锁存。
- S7-T05：重复启动/停止、重新上电、重新校准，旧 generation 和旧轨迹不能自动继续执行。
- S7-T06：实测 stop requested / admission closed / TX drained 时间；**只有有独立证据时**才能填写 actuator safe，不用串口返回时间冒充。
- S7-T07：验证独立急停/电源行为，包括断能后保持力丢失、抓取物掉落等风险；结果与硬件设计一致。
- S7-T08：单指和全手低速受限轨迹，验证位置、速度、温度/负载（若协议可提供）以及长期运行异常监控。
- S7-T09：所有真实异常测试具备可重复步骤、停止条件、观察者、原始日志和风险复盘。

## 通过标准
上电前审查通过；每一台阶的功能测试与风险缓解均通过，实测数据满足**在测试前冻结**的指标，全部证据可复现。若安全硬件能力不足，应标记为 BLOCKED，不得以软件通过替代物理安全验证。
