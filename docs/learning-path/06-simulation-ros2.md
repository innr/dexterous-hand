# S6 — MuJoCo + ROS2 系统集成

**入口**：S5 PASSED。**目标**：在无真实舵机情况下，控制 16 DOF LEAP 模型完成闭环轨迹与异常处理。

## 必会知识
MuJoCo 关节/执行器/约束、位置与力矩执行器区别，ROS2 节点/发布订阅/QoS/执行器/时间源、`joint_states` 与目标命令契约、仿真时钟及日志回放。

## 交付
16 关节 MuJoCo 模型配置、`ros2_control` 适配（或明确的轻量 ROS2 桥接）、`joint_command` / `joint_states` 数据链、可重现 launch 与 demo；控制核心不依赖 ROS2 类型，使用 adapter 隔离。

## 验收测试
- S6-T01：模型具备 16 个关节，名字、方向、限位、home pose、执行器映射有自动核验。
- S6-T02：单关节和 16 关节轨迹运行、返回 home；每个关节追踪时间、超调和误差。
- S6-T03：ROS2 topic 消息格式、时戳、QoS 与频率测试；断订阅/重连不误执行旧命令。
- S6-T04：停止请求后，仿真控制核心拒绝旧 generation 轨迹；复位后先待命再 enable。
- S6-T05：在仿真中注入反馈延迟、丢包、错序和模拟接触，安全状态/日志匹配预期。
- S6-T06：录制至少 3 段独立轨迹，回放复现相同目标序列与可解释的误差。
- S6-T07：从 clean checkout 使用文档中的固定版本依赖和 launch 指令复现全部演示。

## 通过标准
所有自动化验证通过，提供 ROS bag/日志/录屏或数值报告、版本清单及审查结果。仿真中通过只证明该模拟模型及假设下的行为。
