# S5 — 机器人运动学、状态估计与关节控制

**入口**：S4 PASSED（可提前学习理论）。**目标**：从关节位置反馈到运动轨迹、PD 和延迟分析形成可复现的闭环控制能力。

## 必会知识
- 弧度/角度、正逆运动学基础、关节坐标与舵机 ID / 正负方向 / 零位映射。
- PD、阻尼、惯性、摩擦、弹性、饱和与 anti-windup 概念（涉及积分环时）。
- 采样、速度估计、滤波、反馈延迟、每关节时间戳对齐。
- 匀速预测 `q_hat=q+v*dt`、恒加速度误差 `0.5*a*dt^2`；接触时模型失效与安全约束。
- 插值轨迹（三次或五次）、速度/加速度/位置约束，轨迹取消与重规划。
- 区分仿真 torque PD 与 STS3215 内置位置环，不向位置舵机假装下发真实关节力矩。

## 交付
`JointMapper`、`TrajectoryPlanner`、`StateEstimator` 和可离线运行的 `ControlExperiment`；基于日志绘制阶跃/轨迹/延迟/跟踪误差曲线；记录参数、采样周期与单位。

## 验收测试
- S5-T01：角度/弧度、正负方向、限位和 ID 映射的往返与边界测试全部通过。
- S5-T02：在无噪声匀速合成信号中位置预测误差满足浮点容差；在恒加速度情况下测量误差与时间平方关系。
- S5-T03：目标轨迹符合设定位置、速度、加速度限幅（离散计算允许预先定义数值容差）。
- S5-T04：仿真无接触阶跃/轨迹跟踪，按实验前指定的上升时间、稳态误差、超调阈值验收；记录实际数据，不事后放宽。
- S5-T05：在延迟、噪声、饱和、碰撞模型场景中完成参数扫描，识别不稳定/超限并触发对应安全策略。
- S5-T06：解释 Kp/Kd、延迟和机械弹性如何影响能量与振荡；可手推一个简单 PD 数值步进。
- S5-T07：停止与恢复后轨迹目标重新对齐反馈，不出现跳变到旧位置目标。

## 通过标准
数值单测全部通过，至少一份含原始 CSV、绘图脚本、参数表和结论的实验报告；能独立解释模型假设与失效条件。性能阈值由实验前的设计审查冻结。
